FUNCTIONAL REQUIRMENTS

FR 1: When a user enters login information, the system shall verify credentials and allow access if correct.

FR 2: When a user creates or updates an event, the system shall store the event and update the schedule.

FR 3: When events overlap, the system shall detect and notify the user.

FR 4: When a task is marked complete, the system shall update the schedule accordingly. 

FR 5: When a user inputs data, the system shall validate the format and reject invalid entries.


NON-FUNCTIONAL REQUIRMENTS

NFR 1: The system shall store passwords in a hashed format and restrict users to their own data.

NFR 2: The system shall respond to user actions within 2 seconds under normal conditions.

NFR 3: A new user shall be able to create an event without training.

NFR 4: The system shall prevent crashes and display simple error messages.
